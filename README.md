# CSR WebApp
> This app is build for representative side of a casino/betting webapp;
> Can add a customer user level to be a standalone app;
> or just a Chat app for both end users;

## Dependencies
- React
- Typescript
- Zustand
- Axios

## Prerequisites
- Node
- NPM
- Yarn

## Installation
- Clone the repo
- Run `yarn install`
- Run `yarn dev`
